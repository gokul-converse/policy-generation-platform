# Work-from-home policy draft

## Purpose
State the policy's purpose: to provide a concise, reusable draft that communicates when employees may work from home, how to request permission, and the rules for remote work.

## Instructions
1. Analyze the assigned requirement: I want to create a work-from-home policy for our company. Employees should know when they can work from home, how to request permission, and what rules they need to follow while working remotely.
2. Create a minimal policy draft structure that explicitly includes:
- Eligibility/When remote work is allowed
- Request and approval process
- Remote-work rules (security, equipment usage, communication expectations, availability)
3. Ensure the language avoids organization-specific values. The sections should be labeled clearly and ready for policy owner input.
4. Outline a process for policy owners to fill in missing details:
- Identify missing information (who is eligible, applicable locations/hours, how requests are approved, escalation paths, etc.)
- Collect stakeholder input and update the draft accordingly.
5. Validation:
- Confirm the draft covers the three core topics from the input requirement.
- If a topic is ambiguous, note what needs clarification.
6. Output:
- Return a single policy draft document with clearly labeled sections, ready for policy owner review and update.
