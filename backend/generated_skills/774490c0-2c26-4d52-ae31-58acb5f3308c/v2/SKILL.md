# Work-from-home-policy-skill

## Purpose
This skill uses the validated requirement to draft a Work-from-Home Policy in HR, including eligibility, scope, rules, stakeholders, and approvals. It ensures the policy has a clear structure and actionable language.

## Instructions
1) Create a policy skeleton following the standard policy structure: Document control block, Purpose, Scope, Definitions, Policy statements, Roles and responsibilities, Procedures, Exceptions and approval process, Violations, Related policies and legal references, Review cycle and revision history, Acknowledgement/sign-off.
2) Populate the skeleton with concrete details extracted from the validated requirement and ensure alignment with the skeleton; preserve exact numbers and strings from the requirement in the policy; use must/may language.
3) Include a Source Requirements section referencing each referenced requirement by ID with the exact original text (the value of the requirement’s text field).
4) Use placeholders for company-specific values as needed; ensure the policy is actionable and ready for adoption workflows.
5) Return the final policy draft in a reusable format compatible with downstream policy adoption workflows.
