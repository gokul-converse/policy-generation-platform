# it-security-policy-draft

## Purpose
Draft a company IT security policy that covers password requirements, multi-factor authentication, data access permissions, device security, incident reporting, and employee responsibilities for protecting confidential information.

## Instructions
1. Confirm the input scope: IT security policy addressing the six focus areas listed above.
2. Use the company-policy-generator workflow to draft a policy aligned with IT security policy practices, focusing on clarity, enforceability, and scope strictly limited to the input requirements.
3. Structure the draft with clear sections for each focus area:
   - Password requirements
   - Multi-factor authentication
   - Data access permissions
   - Device security
   - Incident reporting
   - Employee responsibilities for protecting confidential information
4. For each focus area, specify baseline expectations at policy level (e.g., high-level requirements) without adding implementation details beyond the scope.
5. Validate that all six focus areas are present and consistently addressed.
6. Output the policy draft in a policy-ready text block with distinct section headings for easy review.
